# NaNoBO 0.2.1 Mac 使用说明

支持 Apple Silicon（M 系列）Mac，macOS 14 或更新。打开 `NaNoBO-0.2.1-macOS-arm64.dmg`，将 NaNoBO.app 拖入 Applications。所有模型在本机运行，无需 Python、WSL、Docker 或 API 账户。当前为 ad-hoc 签名测试版，尚未完成 Apple Developer ID 签名与公证。

## 从一个实验项目开始

1. 点击“新项目”，选择任务：数值优化、Pareto 多目标或分类主动学习。“教学示例”提供四种明确标注的模拟数据，可以先体验完整流程。
2. 定义连续、整数、类别变量和单位。类别用 `|` 分隔。数值变量可填写步长，从下限起算；留空的连续变量可在范围内连续取值。单位仅记录，程序不换算。
3. 设置目标列。数值目标选择最大化或最小化；Pareto 至少两个目标，分别设方向。分类只设一个结果列，并在“分类标签”填写例如 `成功 | 失败` 或多个类别。
4. 在“已完成实验”手动录入，或导入 XLS、XLSX、UTF-8 CSV。表头必须与全部变量、目标名称一致。多工作表的 Excel 会提示选择一张表。空值、重复表头、没有缓存结果的 Excel 公式会报错，不会变成 0。
5. 点击“生成下一批实验”。实测数据不足时执行分散初始设计；模型训练失败会报错，不会假装成功。推荐会避开已测、待实验和批内重复条件。
6. 在“下一批 / 待实验”导出 CSV，完成实验后填入目标列，再导入。对应待实验条件自动移除。CSV 可由 Excel 打开。
7. 使用“保存”或 ⌘S 保存 JSON 项目；⌘⇧S 另存版本。项目包括原始结果、待实验条件、配置、计算历史和最近分析。数据不自动上传。

## 可执行配方空间

使用 BoTorch 引擎，在变量表填写实际加液／温控步长；在“配方约束 / 候选表”中添加：

- 总量或线性规则：例如 A + B = 2.5，或 2 × A + B ≤ 3。填写系数、关系和右侧值，不能混用不同量纲。
- 配比范围：例如 0.5 ≤ A / B ≤ 2。分母必须大于 0。
- 合法候选表：导入只含变量列的 XLS/XLSX/CSV。下一批只从该表选择，同时满足其他规则。表中的重复或过于接近的配方会被拒绝；历史实测允许不在候选表中。

约束参与候选生成与选择，不是在推荐后舍入。观测、待实验和候选均需要符合项目边界、步长和联合约束。若需修改被规则引用的变量，可先点“清除联合限制”，再修改；步长需要单独在变量表清除。

有限域最多检查 200,000 个源组合；较大域请增大步长或导入精简候选表。一次模型评分最多使用 4,096 个合法未测候选；连续域和较大候选表使用固定种子的子集。界面会说明搜索范围，因此排序不代表整个连续空间的全局最优。过窄、矛盾或难以采到的可行域可能需要改用显式候选表。

## 推荐依据与可视化

生成推荐后打开“模型与可视化”；需要留一验证时点击“分析与交叉验证”。分析不会增加待实验条件。修改数据、目标或实验空间后，旧分析会失效，需要重新计算。

- 候选表：变量、预测均值、模型标准差、采集分值、排名及本批是否选中。采集分值只在同一次计算内比较；批内后续选择会考虑刚选中的待实验点。
- 预测与探索：候选预测区间、均值与不确定性、采集分值排序。区间描述模型，不等于实验测量误差。
- 模型验证：用与推荐相同的实际模型逐个留出、重新拟合，展示预测—实测散点、误差、RMSE、MAE 和适用时的 R²。超过 30 条观测时使用可复现的最多 30 个留出点，并显示已验证数量。
- 数据分布：数值直方图、类别计数、实测历史及最佳值曲线。
- Pareto：选择不同目标作二维、三维图，突出实测非支配点；超体积曲线以同一次分析的固定参考点计算。自动参考点会随新增数据变化，跨次分析不应直接比较超体积绝对值。
- 分类：各候选的类别概率、分类熵、类别分布、留一验证混淆矩阵与准确率。高熵条件用于探索类别边界，不能直接解读为最容易成功的配方。没有观察到至少两个类别时，不提供虚构的分类概率。

图表工具栏支持缩放、平移；点击候选点可查看条件。选中图表后可导出 PNG、PDF、SVG，也可导出候选预测 CSV。没有相应分析时显示原因，不绘制伪造结果。

## 引擎与使用范围

Gryffin 保留原生单目标和 Chimera 层级多目标；Atlas 保留原生单目标与批量推荐。新增的步长、联合约束、候选表、Pareto、分类及模型诊断在 BoTorch 工作流使用。BoTorch 数值任务固定使用 GP，分类固定使用概率分类器；没有模型或采集函数的选择菜单。

Gryffin、Atlas 的原生推荐结果没有套用另一个模型来冒充其预测或验证。Atlas 的多保真、元学习、描述符输入等高级能力尚未开放。推荐不是实测，不保证最优；算法优劣需要相同任务与实验预算的比较。

Windows 按当前安排暂缓；Intel Mac 尚无完整版。对外分发前还需 Apple Developer ID 签名／公证和更多 Mac 设备验证。许可证及源码位于 DMG 的 Source-and-Licenses。
